# 🎲 Lanzador de d20 Universal Pro / Universal d20 Roller Pro

Herramienta web ligera y personalizable para lanzar dados d20 con modificadores, presets de D&D/Rol e historial de tiradas.  
*A lightweight and customizable web tool for d20 dice rolling with modifiers, TTRPG/D&D presets, and roll history.*

👉 **[Probar la aplicación / Live Demo](https://prox97z.github.io/lanzador-d20/)**

### 📌 Sobre este proyecto
Este es un proyecto personal creado por **Prox** por gusto y diversión para facilitar las tiradas en partidas de rol.

> ⚠️ **Nota:** No soy programador. Este proyecto fue desarrollado utilizando **Inteligencia Artificial** como asistente de código para dar forma a la idea, diseño y lógica de la herramienta.

### ✨ Características
* 🚀 **Sin lag (Ultra fluido):** Altamente optimizado mediante aceleración por hardware para funcionar sin caídas de fotogramas en computadoras sencillas o laptops.
* 🎲 **Modo Dado Grande (Overlay):** Modo con animación 3D centrado a pantalla completa para mayor visibilidad al transmitir o jugar en vivo.
* ⚡ **Ventaja y Desventaja:** Lanza dos dados simultáneamente seleccionando automáticamente el resultado más alto o más bajo.
* 🛠️ **Presets personalizables:** Configuración y guardado local rápido para ataques, habilidades y salvaciones.
* 📊 **Historial e indicadores:** Registro en tiempo real de tiradas previas junto a un calculador automático de promedio.
* 🎨 **3 Temas visuales:** Alterna al instante entre las interfaces Violeta, Neón y Rojo Tinto.
* 🔊 **Efectos de sonido:** Retroalimentación de audio ligera integrada al lanzar el dado.
* 📱 **Diseño Adaptativo:** Funciona en PC, laptops y dispositivos móviles.

## us EN - English

### 📌 About this project
This is a personal project created by **Prox** just for fun, designed to streamline dice rolling during tabletop RPG sessions.

> ⚠️ **Note:** I am not a programmer. This project was built using **Artificial Intelligence** as a coding assistant to bring the overall idea, design, and logic to life.

### ✨ Features
* 🚀 **Lag-Free Performance:** Highly optimized with CSS hardware acceleration to run smoothly on low-end hardware and laptops without frame drops.
* 🎲 **Centered Big Dice Mode (Overlay):** Full-screen 3D animation mode for enhanced visibility during live sessions or screen sharing.
* ⚡ **Advantage & Disadvantage:** Roll two dice simultaneously with automatic calculation of the highest or lowest result.
* 🛠️ **Customizable Presets:** Quick configuration and local saving for attacks, skill checks, and saving throws.
* 📊 **History & Stats:** Real-time logging of past rolls along with an automatic average calculator.
* 🎨 **3 Visual Themes:** Toggle seamlessly between Purple, Neon, and Dark Red interfaces.
* 🔊 **Sound Effects:** Built-in lightweight audio feedback when rolling.
* 📱 **Responsive Design:** Seamless performance on desktop, laptop, and mobile screens.
